\# Docker Multi-Stage Build Assignment



\## Objective

Build a Java web application using Maven in a builder stage, then copy only the generated WAR file into a lightweight Tomcat runtime image. Verify that the application runs through a mapped host port.



\---



\## Prerequisites

\- Docker installed and running

\- Terminal/PowerShell access

\- Internet access to pull Maven and Tomcat images

\- No local Maven/Java installation required
